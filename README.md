# MERN E-Commerce Store with Real-Time Chat

## Overview
A full-stack e-commerce platform built using the MERN stack, featuring product browsing, cart functionality, and real-time customer communication via live chat.

## Tech Stack
- Frontend: React, JavaScript, HTML, CSS
- Backend: Node.js, Express.js
- Database: MongoDB
- Real-Time: Socket.io
- Tools: Postman

## Key Features
- Full CRUD functionality for products and users
- Real-time chat using Socket.io for instant communication
- Dynamic shopping cart with state management
- RESTful APIs for backend services

## Challenges & What I Learned
- Managing application state across components in a full-stack environment.
- Handling real-time data updates without performance issues.
- Designing scalable backend APIs.
